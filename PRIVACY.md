# Privacy policy

SQLTools is a desktop database client. It does not collect telemetry, analytics or
usage data.

- Database connections are opened only to the server the user configures. Credentials
  and query text are sent only to that server.
- Passwords are stored in the operating system keyring when the user asks to save them;
  they are never written to the connection JSON file.
- Connections, preferences, templates and workspaces are stored locally in the user's
  configuration directory.
- The update check, when an endpoint is configured, contacts only that endpoint. No
  endpoint is configured in the current builds.
- No information is transferred to other networked systems unless specifically
  requested by the user or the person installing or operating the program.
